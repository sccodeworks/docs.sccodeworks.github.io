Processing Dialog​

  • From the "Maintenance menu” take the "Work With Items" option.
  • Locate the item and scroll to find the option number for the "Maint Whse Ops." Type this option next to the item.
  • When you press the <Enter> key, the following panel will be displayed.

Maintain Item Warehousing Information

  • In the Product Management portion of the panel at the bottom of the screen, the first property is the Warehouse Zone. Key the zone code that you want to associate with this item (field must be alpha).
  • If you are unsure of the code, use the <F4> key to get a list of the zones defined for this building and select from the list.

The following depicts the zone selection panel.

Warehouse Zone Selection Panel

  • Scroll through the list until you find the zone you are looking for, place the cursor on the line and press the <Enter> key to select the zone. The zone value will return to the maintenance panel.
  • Press the <Enter> key to record the zone for this item.

To associate a zone with a location,

  • Take the "Work With Warehouse Maps" option off the "Maintenance" menu.
  • Find the location that you wish to maintain and place the "Change" option next to it.
  • When you press the <Enter> key, the following panel will be displayed.

Maintain Warehouse Map

In the middle of the panel, you will find the W arehouse Zone property.

  • Key your zone code or use the <F4> key to get a list and select the appropriate zone for this location.
  • Press the <Enter> key to record the zone.
  • If you are setting the zone for several contiguous locations, the "Group Change" option can be used.
  • See the WDLS setup guide for details on Maintaining Warehouse Map Locations for details on the "Multiple Location Setup" panel.
  • Once the range is defined, key the zone code or press the <Enter> key to add/change the zone for all locations in the range. In either case, you will return to the "Work With Warehouse Map" panel when the process is complete.
