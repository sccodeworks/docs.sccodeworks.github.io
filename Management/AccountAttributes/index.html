Processing Dialog​

  • From the "A/R Main Menu”, choose the "Work With Account Attributes" option and press <Enter>. The following panel displays.

Work With Attributes

In the body of the panel is a list of any attributes that have already been defined.

  • To change an existing Attribute, place the "Change" option next to it and press the <Enter> key.
  • To add a new attribute to the item, press the <F6> key. In either case, the following depicts the maintenance panel that appears.

Maintain Attributes

  • When adding a new Attribute, enter the Attribute name.
    • If maintaining an existing attribute, the - Attribute - field cannot be changed, only the - Attribute Description - can be adjusted.
  • Enter/Change the description
  • Press <Enter>.  You will be returned to the "Work With Attributes" panel.
  • To delete an Account Attribute, place the "Delete" option next to the desired account and press <Enter>.  Take caution as there is no "Delete Confirmation" screen
