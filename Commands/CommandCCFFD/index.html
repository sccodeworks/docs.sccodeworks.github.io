Processing Dialog​

The CCFFD command will retrieve a list of the fields within a specific file.  To view this information, press the <F10>=Command key from any WDLS menu screen.  This will display a window at the bottom of the screen as seen below:

One parameter must be passed with the CCFFD command.  This parameter is the file name.  This parameter can be entered from the original command prompt on the menu screen as seen above.  However, if a file name is not entered, a separate screen will be displayed.  It is shown below:

If the above screen is displayed, fill in the appropriate file name.  The Library field will default to your library list.  This can be changed to another library if necessary.  Once you have completed these fields, press <Enter>.  Another screen will be displayed that shows the information about the requested file.

On this screen, you can see the information about the various fields within the desired file.  The first bit of information is the Field Name.  Second is the buffer length.  The fourth column lists the number of digits following the decimal point if applicable.  The next column states the types of the field.  Most commonly, there are either A-alphanumeric or S-signed numeric.  Lastly, a description of each field is listed.
