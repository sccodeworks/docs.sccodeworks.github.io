Processing Dialog​

The CCKEYS command will retrieve a list of the key fields within a specified file.  To view this information, press the <F10>=Command key from any WDLS menu screen.  This will display a window at the bottom of the screen as seen below:

One parameter must be passed with the CCKEYS command.  This parameter is the file name.  This parameter can be entered from the original command prompt on the menu screen as seen above.  However, if a file name is not entered, a separate screen will be displayed.  It is shown below:

If the above screen is displayed, fill in the appropriate file name.  The Library field will default to your library list.  This can be changed to another library if necessary.  Once you have completed these fields, press <Enter>.  Another screen will be displayed that shows the information about the file passed as a parameter.

On this screen, you can see the information about the key fields within the desired file.  The first column lists the sequence of the key fields.  This is followed by the field name.  The next column lets you know whether the records are sorted in ascending or descending order based on the particular key field.
