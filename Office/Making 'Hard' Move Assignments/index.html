Making "Hard" Move Assignments​

Processing Summary​

  • Work With Movement Queue
  • Assign A Move
  • De-Assign a Move

Processing Dialog​

From the "Radio Frequency" menu take the "Work With Movement Queue" option. Use the search criteria to locate the move(s) you wish to assign. Place the "Assign" option next to a move and press the <Enter> key. The following panel will appear.

The move queue transaction number appears in the upper right corner of the panel along with information provided to identify the move.  There are two input fields - the operator you wish to assign the move to, and the priority of the move.  Key the operator's user ID to make the assignment.  A valid operator must be supplied to continue.  The current priority will default.  Key over the priority to change it.  After you press the <Enter> key, the assignment will be made, and the status of the move will change to 'AS' for assigned.

When the operator takes the "Scheduled Moves" option from the "Forklift" or "Handheld" menus, the programming will check for existing assigned moves.  If they exist, they will be presented to the operator first before any work assignments are matched to the other available move queue entries.  The assigned moves will be processed in priority sequence.

Once a move is assigned to an operator, it will not be given to any other operator.  During normal scheduled move processing a new move is assigned each time the prior move completes.  When the operator exits the scheduled move process, the last assigned move, which typically will be incomplete, is de-assigned making it available for other operators.  In a mixed pallet move, each individual move that makes up the pallet is assigned as it gets selected.

If an assignment is made to an operator that has stopped working, or if a "hard" assignment was made that you wish to release, take the "De-Assign" option from the "Work With Movement Queue" panel.  No additional panels will be displayed.  The operator will be removed from the queue entry and the status will be reset to 'AC'.
