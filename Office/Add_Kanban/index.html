Processing Summary​

  • Work With Kanban

Processing Dialog​

  • From the “Requisitions Process” screen, select the "Work With KANBAN" option, then press <F6> to create a new Kanban Card, and press <Enter>. The following panel displays:

Maintain Kanban

  • Create a new Card Number by typing in the fields. Mandatory fields to type on the panel are:
    • Card Number - - This is the unique tracking number for this Kanban.
    • Storer Number - - This is the storer number recorded for this Kanban.
    • Item Code - - This is the Item number this Kanban relates to.
    • Requested Quantity - - This is the Kanban Quantity. Each request of this KanBan will create a requisition for this quantity.
    • Deliver To Location - - This is the location that is requesting the parts.
  • Press <Enter> to create the Kanban Card.
