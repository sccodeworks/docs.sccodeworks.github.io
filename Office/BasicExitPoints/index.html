Processing Summary​

  • Determine if a Global setting is sufficient
  • Add Storer specific Exit Points

Processing Dialog​

  • Find the list associated with the type of storer to be setup
  • From the Security Menu select option = Work with Exit Points
  • Check for a Global setup (global Exit Points will have no storer associated and will be used for every storer that does not have a storer specific Exit Point
    • If a Global Exit Point is present, does it equal the value needed for this storer?
      • Yes - no need to create a Storer specific one
      • No - Create a Storer Specific record
  • Create a Storer Specific Exit Point
    • From the Work with Exit Points panel select <F6> to add
    • Storer: Enter the Storer number for whom this Exit Point will be used. (Pressing <F4> will present a list of Storers to select from
    • Exit Point: Enter the Exit Point you wish to add. (Pressing <F4> will present a list of available Exit Points.)
    • Choice: Press <F4> and select the appropriate choice for this storer from the list
    • Press <Enter> to create the record and return to the Work With Exit Points Panel
  • Repeat steps 3 and 4 for the remaining Exit Points
