Processing Details​

Sign on to the test environment (normally ETEST) at the customer and jump to: EDTLIBL, get the correct data library you need to copy to, normally WDLSDTEST, but we do have other data libraries (like the traffic one shows as seq # 60 in this example) and the name can vary on Shared boxes like the SAG facilities) so always check for the correct library name, don't copy to the wrong library, if ever unsure, ask someone else first. Copy the library name.

Next, from the production menu, go to Work with Storers and enter the storer number, check your options, normally option 10 is Export, when you take the Export Option the below screen appears, the “To Library:” is where you paste the test data library, and normally put down "N” for Submit to batch. By putting down N, it doesn’t hold up the customers current operations. Then press enter once you verify/are ready to execute. It will take a while to run depending on how much data they have to transfer over.

It will lock your screen for some time. So, wait until it's finished running before going into test to check for the storer, forms, tallies or orders, items, etc.

Sometimes it will bail as it finds mismatches and can’t copy everything over but it will get your Storer and some info over there. Just check that the data you need is there or know what you will have to create manually to test.

The storer will then show in the testing environment.
