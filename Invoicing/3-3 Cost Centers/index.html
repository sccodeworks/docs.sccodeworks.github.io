Processing Dialog​

From the A/R Main menu, select "Work With Cost Centers".  Below is an example of the screen that will appear with the current Cost Centers :

To create a Cost Center , select the "Create" option.  The following screen will appear.

Place a letter beside to the Cost Center Code to indicate the newly created Cost Center .  The standard cost centers supported by WDLS Finance reports are H-handling, S-Storage, M-Miscellaneous, C-Clerical, A-Administrative, and T-Transportation .  Note: Additional cost centers may be established, but some standard WDLS Finance reports, i.e. revenue summary report, will categorize the Cost Centers as "Unknown".

The Cost Center Suffix is used to create a Subgroup of revenue within cost center.  If a subgroup of the Cost Center is needed or desired, place a number 0-9 on the Cost Center Suffix line to create a subgroup.  A suffix of 00 indicates that the description supplied applies to the cost center in general and will be used whenever cost center totals are supplied.  Any other suffix establishes a category within the cost center.  For instance, the S-Storage cost center can be broken into a suffix of 01 for receiving storage, and 02 for recurring storage.

The Cost Center Description is displayed on various reports and panels to describe the associated revenue figures.  Type in the Cost Center Description and press "Enter".  The new Cost Center will now show up on the "Work With Cost Center" screen.

To change the Cost Center Code description or delete a Cost Center suffix, select the "Change" option on the "Work With Cost Center" screen beside the Cost Center Code that you would like to modify.  The following screen will appear:

Make the necessary changes to the Cost Centers as desired.

Once the entries are complete, press <Enter> to record the data and return to the "Work With Cost Center" panel.
