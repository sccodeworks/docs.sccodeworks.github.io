Processing Dialog​

From the “Radio Frequency” menu, choose the Scheduled Moves option to pick an order. After pressing the <ENTER> button, an Order Summary will pop-up showing the Consignee, Reference #, Carrier, the number of pallets, and the number of pieces. The pop-up screen is shown below.

Page down to see if there are any comments or special instructions. Then press <ENTER> and select the initial item for the mixed pallet. Press <ENTER> again and then another pop-up screen will appear that will direct the first location, item, lot, and quantity to pick. This pop-up screen is shown below.

The input lines are:

  • Scan From Location
  • Scan/Enter Item
  • Quantity
  • Scan/Enter Lot

Press <ENTER> and a pop-up may appear saying “No additional partial pallet moves are required to complete this order”.

Press <ENTER> again if you get this screenshot.

The last input line is:

  • Scan To Location (Stage Location)

Pick Problem

If there is an issue with the product in the instructed location, such as wrong item, lot, or missing; do not continue with processing the instruction. Please follow the bellow instructions.

  • Press <F7> for the Report Problem option
  • Continue with next picking instruction

NOTE: This will not work if you are already processing the move. Important to verify every instruction before processing. Marking instruction as a problem will give the Supervisor an indication that you have an issue with that pick and needs to be verified so you can continue. Once Supervisor has corrected the problem, pick instruction will be available again for processing.
