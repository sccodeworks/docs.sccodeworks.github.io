Processing Dialog​

  • From the "Supply Management" menu, select the "Work With Supply Transactions" option. You will be shown a list of the existing supply transactions.
  • Press the <F6> key to create a new transaction. The following panel displays.

Maintain Supply Transaction Panel

  • Key the Storer, Consignee, or Carrier along with the Type of supply you are adjusting. For an adjustment, key a document Type of "A". Typically, there is no Document Number relating to an adjustment. The Location field is optional and used solely for tracking purposes. There is no logic to track supplies by location currently.
    • The three - Quantity - fields are presented to record your adjustment quantity.  A positive adjustment that increases the quantity in the pool should be entered in the returned field.  A negative quantity to reduce the pool should be recorded in the used or rejected fields.
    • The - Pool - affected flag indicates if the storer, consignee, or carrier pool should be affected by the adjustment.  The - Whose invoice - flag determines the party that should be charged if the adjustment results in a chargeable transaction.  The - Reason Code - can be used to codify the reason you are making an adjustment.  A special reason code of "NC" will ensure that no charge will be incurred even if the adjustment would normally be considered a billable transaction.
    • The - Supply ID Number - is used to record a tracking number if the supply requires serialized tracking.  If this is the case, the quantity involved should always be one.
    • The - Rate Number - is shown for display purposes only.  It will appear if a transaction is pulled for update.  It indicates the number of the rate record that was determined by the program logic as applying to this transaction.  The - Status - is the last field to display.  The status defaults to "AC" for all adjustments.
  • When you press the <Enter> key, your adjustment will be added, and you will return to the "Work With Supply Transactions" panel.
