Processing Details​

Take the "Cycle Count Report" option from the "Cycle Count" menu. After you press the <Enter> key, the following prompt will appear.

Enter the storer number and suffix of the storer whose cycle count data you would like to view. Press <Enter> to submit the report. To view the report, jump to WRKSPLF and take option 5 to display the report you generated.

The cycle count report will list all items for the storer. First, the item code is displayed followed by the item description.
