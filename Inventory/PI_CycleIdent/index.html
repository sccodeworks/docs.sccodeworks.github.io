  • Maintain An Item Cycle Schedule

Processing Details​

To access the item cycle schedule, take the "Work With Item Cycle Schedule" option on the "Physical Inventory" menu. This will bring up a panel that lists all items with a cycle schedule entry. The following depicts that panel.

In the body of the panel, the storer , item code , item description , and date last counted are listed for each entry.  The last column contains the status of this entry.  If the status is "AC" it indicates that this entry is active and will be included in the next cycle count extract for this account.  If the status is "CL" it indicates the entry was counted, and the date and time will indicate when the last cycle count extract was made that included this item.

You can add or change the status of an existing entry by pressing the <F6> key or placing the "Change" option next to the entry and pressing the <Enter> key.  In either case you will see the "Maintain Item Cycle Count Schedule" panel.  The following depicts that panel.

If you wish to delete a cycle count schedule entry, place the "Delete" entry next to it and press the <Enter> key.  No panel will be displayed, and the record will be deleted.  You will then return to the "Work With Item Cycle Count Schedule" panel.
