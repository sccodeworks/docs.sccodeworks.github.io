Processing Summary​

  • Extract Cycle Count Book

Processing Details​

After you have built the inventory files, you can take the "Extract Cycle Count Book" option from the "Physical Inventory" menu. The programming will clear any existing book and count information and then load the book entries. The options that were selected when the file sets were created will control the extract process. The following depicts the panel that will be displayed when you take this option.

Key in the Book Name, up to ten characters, that identifies this Book.  This is the book name that you specified when you built the inventory file set.

The processing will use the information captured during the build process to identify the Storer Number and Suffix of the account.  The item cycle count schedule entries will be used to determine which items should be counted.  Each item record for the account that is in an "AC" status will result in all of that items locations that contain a non-zero quantity in any of the inventory buckets will be included in the book.

The book lines will be added based upon the Sort Order specified during the build process.  Five choices are supported: *ITEMLOC, *ITEMLOT, *ROUTING, *LOCATION, and *LEVEL.

Once the Book Extract information is complete, press the <Enter> key.  The extraction process will be submitted as a batch job.  You will return to the menu.
